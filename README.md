# Feiya - Uzum Market Reklama Banneri

Uzum Market uchun tayyorlangan mahsulot reklama posteri (3:4 nisbatda).

## Mahsulot
- **Nomi:** Novo namlantiruvchi qo'l kremi (*Увлажняющий крем для рук*)
- **Maqsad:** Uzum Market do'koni uchun reklama va mahsulot kartochkasi
